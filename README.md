# Norwegen Solo 2026

Reisevorbereitungs-App für den Solotrip nach Norwegen, 23.10. – 07.11.2026.

Eine einzige Datei: `index.html` im Browser öffnen (oder per GitHub Pages hosten). Kein Build, keine Installation.

## Funktionen

- **Übersicht** – Countdown, Fortschritt (Unterkünfte, To-dos, Packliste, Budget), nächste fällige Aufgaben
- **Route** – alle 16 Tage mit Ort, Plan, Transport, Unterkunft, Notizen; Sonnenauf-/untergang und Nordlicht-Dunkelheit pro Ort (inkl. Zeitumstellung am 25.10.2026)
- **Packliste** – auf Herbst/Winter in Norwegen zugeschnitten, erweiterbar
- **To-dos** – Vorbereitung mit Fälligkeiten, Notfallkontakte & Notizen
- **Budget** – Plan pro Kategorie, Ausgaben in NOK oder Heimwährung mit Umrechnung
- **Tipps** – Notrufnummern, Solo-Sicherheit, Transport, Nordlicht, Alltag

Daten werden im Browser gespeichert (localStorage); über „Daten kopieren / einfügen" lassen sie sich sichern oder auf ein anderes Gerät übertragen.
